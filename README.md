# 库街区 Token / DID 复制版（3.5）

基于库街区 3.5 官方包去除加固后重打包的修改版，仅新增一个功能：**在设置页查看并复制自己的 Token 与 DID**。

## 功能

- 设置页新增「复制 Token / DID」入口，点击进入独立页面（不是弹窗）
- Token 与 DID 分别展示，点击数值本身或右侧「复制」按钮即可复制纯值
- 复制后从屏幕下方提示「请保护好自己的凭证」
- 需要先在 App 内登录；未登录时 Token 为空

## 下载

从 [Releases 页面](https://github.com/PaperKito/KuroBBS-TokenCopy/releases/latest) 下载 `kurobbs-3.5-tokencopy.apk`（约 43 MB）。

## 安装

1. 先卸载设备上已安装的库街区（官方版或旧改版）——签名不同，无法直接覆盖安装。
2. 安装本目录下的 APK。
3. 打开 App 并登录，进入「我的 → 设置 → 复制 Token / DID」。

## 说明

- 原包加固已去除，使用 v1 + v2 + v3 完整签名，`resources.arsc` 已做 4 字节对齐，可在 Android 11+ 上安装。
- 凭据读取自 App 自身私有数据，**不需要 root**。
- 本仓库只提供成品 APK，不包含重签密钥、构建脚本与中间产物。
